# Raj Aghara — Full Stack Developer & AI/ML Portfolio

A modern, high-performance neo-brutalist interactive portfolio website built with custom 3D animations, GSAP (ScrollTrigger, SplitText, Flip, Inertia), and Lenis smooth scrolling.

---

## 🚀 Live Demo & Local Setup

### 1. Run with Python (Recommended)
From the project root directory, run:
```bash
python -m http.server 8000
```
Then visit:
👉 **[http://localhost:8000](http://localhost:8000)**

### 2. Run with VS Code
- Open the project in VS Code.
- Right-click `index.html` and select **"Open with Live Server"**.

### 3. Run with Node.js
```bash
npx serve .
```
